# 🍽️ 오늘의 메뉴 추천기 (Random Menu)

오늘 뭐 먹을지 고민될 때 버튼 한 번으로 랜덤 메뉴를 추천해주는 웹 애플리케이션입니다.

## ✨ 주요 기능

- 🎲 **랜덤 메뉴 추천**: 슬롯머신 스타일 스피닝 애니메이션과 함께 메뉴 추천
- 🎊 **축하 효과**: 메뉴 확정 시 화면 가득 터지는 콘페티(Confetti) 파티클 효과
- 🏷️ **카테고리 필터링**: 전체, 한식, 중식, 일식, 양식, 분식 별 맞춤 추천
- 📋 **추천 히스토리**: 최근 추천받은 메뉴 히스토리 보관 (최대 5개)
- 🎨 **모던 UI/UX**: 다크 모드, 블러 글래스모피즘(Glassmorphism), 부드러운 애니메이션 배경

## 🚀 사용 방법

1. `index.html` 파일을 웹 브라우저(크롬, 엣지 등)로 실행합니다.
2. 상단 카테고리(전체, 한식, 중식, 일식, 양식, 분식) 중 원하는 종류를 선택합니다.
3. **[🎲 메뉴 추천하기]** 버튼을 클릭하면 슬롯 애니메이션 후 오늘의 메뉴가 나타납니다!

## 🛠️ 기술 스택

- **HTML5**
- **CSS3** (Vanilla CSS, Glassmorphism, CSS Keyframe Animations)
- **JavaScript** (ES6+, Canvas Confetti API)
